## Xometry Clone
A clone of Xometry, a platform that connects customers with manufacturers for custom parts. This project replicates key features of Xometry to provide a similar experience for users to request quotes for 3D printing, CNC machining, and other manufacturing processes.

# Features
User Authentication: Sign up, log in, and manage user profiles.
Request Quotes: Users can upload CAD files and request custom quotes for various manufacturing processes.
Part Details: View detailed information about parts, including materials, processes, and pricing.
Order Management: Track orders and view past projects.
Admin Dashboard: Admin panel for managing users and orders.

## Technologies Used
Frontend: React, Redux, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT (JSON Web Tokens)
